# Coleções do Postman

- Importe `LojaDoBem.postman_collection.json` para usar as rotas existentes, agrupadas por perfil. A coleção usa os perfis da branch `feature-alterar-roles`.
- Importe `LojaDoBem.fluxos-propostos.postman_collection.json` para revisar o contrato de pré-cadastro, crédito e venda. Essas rotas ainda não estão implementadas.
- Ajuste `baseUrl` e preencha localmente o token do perfil que deseja testar. As coleções não incluem credenciais nem CPFs reais.
